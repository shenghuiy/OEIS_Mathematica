# A401118: subsets of {1..n} with no LCM triangle

`src/wolfram/A401118.wl` is a Wolfram Language package (context `OEIS`) for [A401118](https://oeis.org/A401118), "Size of the largest subset of {1..n} having no 3-element subset with all pairwise LCMs equal" (Mark Ma, October 2026). It computes single terms with a compiled exhaustive search.

## The sequence

Call three distinct numbers $\{x, y, z\}$ an *LCM triangle* when

$$\operatorname{lcm}(x, y) = \operatorname{lcm}(y, z) = \operatorname{lcm}(z, x).$$

$a(n)$ is the size of the largest subset of $\{1, \dots, n\}$ that contains no LCM triangle. Erdős problem #536 asks how $a(n)$ grows. The terms begin

```
1, 2, 3, 4, 5, 5, 6, 7, 8, 9, 10, 10, 11, 12, 12, 13, 14, 15, 16, 16, 17, 18, 19, 19, ...
```

Examples from the OEIS entry:

- $a(6) = 5$. The only LCM triangle in $\{1..6\}$ is $\{2, 3, 6\}$ (every pairwise LCM is 6), and removing any one of its elements leaves none.
- $a(12) = 10$. Removing 2 and 4 leaves no LCM triangle. Ten is the most possible, because $\{2, 5, 10\}$ and $\{3, 4, 12\}$ are disjoint LCM triangles, so at least one element of each has to go.

## Loading and calling

From the repository root:

```wolfram
Get["src/wolfram/A401118.wl"];
OEIS`A401118[12]               (* 10 *)
OEIS`A401118 /@ Range[24]      (* the first 24 terms *)
```

`A401118[n]` takes a positive integer `n` and returns $a(n)$. The first `Get` compiles three functions, which takes about 30 s.

## How it works

The search follows the Python program in the OEIS entry: for $k = n, n-1, \dots$ it tries the $k$-subsets of $\{1..n\}$ in lexicographic order and returns the first $k$ that has one with no LCM triangle. Every piece is compiled with `FunctionCompile`.

- `a401118GoodQ[s]` takes a sorted subset as a packed integer array and checks its triples, stopping at the first LCM triangle.
- `a401118KSubsets[n, k]` is an [`IncrementalFunction`](https://reference.wolfram.com/language/ref/IncrementalFunction.html): a compiled function that pauses at each `IncrementalYield` and resumes when the next value is asked for. It yields the $k$-subsets in the order of `Subsets[Range[n], {k}]`. To get the next subset, it adds 1 to the rightmost entry that can still grow and resets the entries after it to consecutive values.
- `a401118Search[n]` runs the loop over $k$. Compiled code can use an incremental function as a `Do` iterator, `Do[..., {s, a401118KSubsets[n, k]}]`, so no list of subsets is built, and the loop stops at the first subset that passes.

`a401118SearchIncremental[n]` does the same search with the built-in iterator [`IncrementalObject["Subsets"]`](https://reference.wolfram.com/language/ref/incrementalobject/Subsets.html) (new in 15.0) and only the triangle test compiled. That object does not compile, so this loop runs at top level. The tests use it as an independent check of `a401118KSubsets`.

All helpers are in `` OEIS`Private` ``; only `A401118` is public.

## Performance

Measured on Windows 11 with Mathematica 15.0.1, run with `wolframscript -file`. "Pure" is the uncompiled translation of the OEIS Python program (see `vs-definition` in the tests).

| n | `A401118` | `a401118SearchIncremental` | pure |
|---|---|---|---|
| 20 | 0.041 s | 0.13 s | 2.17 s |
| 22 | 0.094 s | 0.11 s | 4.32 s |
| 24 | 0.72 s | 0.80 s | 28.95 s |
| 28 | 3.5 s | | |
| 30 | 27 s | | |

Most of the speedup comes from compiling the triangle test; the two iterators run at nearly the same speed. The search still examines subsets one at a time, so the time grows exponentially with $n$, and this is no way to reach the 656 terms in the OEIS b-file. Those were computed as an integer linear program: maximize the number of chosen elements, with at most two chosen from each LCM triangle.

## Checks run

`test/wolfram/A401118.wlt` (10 cases, about 40 s with the compile) checks:

- `A401118` against the first 24 terms of the OEIS DATA section.
- `A401118` against the uncompiled definition for $n \le 16$.
- `a401118SearchIncremental` against `a401118Search` for $n \le 20$.
- That `a401118KSubsets[7, 3]` yields exactly `Subsets[Range[7], {3}]`, in the same order.
- The examples above: the triangles $\{2, 3, 6\}$, $\{2, 5, 10\}$ and $\{3, 4, 12\}$, $a(6) = 5$, $a(12) = 10$, and that $\{1..12\} \setminus \{2, 4\}$ has no triangle.
- That only `A401118` is in the public `` OEIS` `` context.

$a(25), \dots, a(30)$ from `A401118` (20, 21, 22, 23, 24, 24) also match the OEIS DATA section; they are not in the tests because they take about 30 s.
