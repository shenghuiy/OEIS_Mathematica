# A101199: partitions of n with rank 2

[A101199](https://oeis.org/A101199) is the number of partitions of n with rank 2, where the rank of a partition is its largest part minus its number of parts. It has no package of its own: it is `PartitionRankCount[2, n]` from `src/wolfram/A101198.wl`, the package for rank 1. The derivation, the proof of the generating function and the timings are on the [A101198](A101198.md) page; this page gives what is specific to rank 2.

**Notation.** As on the A101198 page, `N(m, n)` is the number of partitions of n with rank m and `p(n)` is `PartitionsP[n]`.

## The sequence

The terms for n = 1, 2, 3, … begin

```
0, 0, 1, 0, 1, 1, 2, 2, 3, 3, 6, 6, 9, 10, 15, 16, 23, 27, 36, 42, ...
```

For example a(10) = 3: the partitions 6+2+1+1, 5+4+1 and 5+3+2 each have a largest part two more than their number of parts. The first nonzero term is a(3) = 1, from the single part 3 (rank 3 − 1 = 2). By conjugation, a(n) also counts the partitions of n with rank −2, those with two more parts than their largest part.

The OEIS entry gives the asymptotic a(n) ~ π e^(π√(2n/3)) / (3 · 2^(9/2) · n^(3/2)) (Kotesovec), the same as for rank 1; the ratio of a(n) to it is 0.959, 0.990 and 0.997 at n = 100, 1000 and 10000.

From the repository root:

## The formula for rank 2

Dyson's rank generating function, equation (2.12) of Atkin and Swinnerton-Dyer (1954), with m = 2:

```
Sum_{n>=1} N(2, n) x^n  =  Sum_{k>=1} (-1)^(k-1) x^(3k(k+1)/2) (1 - x^k)  /  Prod_{r>=1} (1 - x^r)
```

since k(3k − 1)/2 + 2k = 3k(k + 1)/2. Reading off the coefficient of xⁿ, the two offsets are 3k(k+1)/2 and k(3k+5)/2:

```
a(n)  =  p(n-3) - p(n-4) - p(n-9) + p(n-11) + p(n-18) - p(n-21) - ...
```

with p(j) = 0 for j < 0. The terms with offsets 3, 9, 18, … alone, `p(n−3) − p(n−9) + p(n−18) − …`, are the Hopkins–Sellers count of all partitions with rank at least 2 (see the Garden of Eden paragraph on the [A101198](A101198.md#how-it-works) page), so the terms with offsets 4, 11, 21, … count those with rank at least 3. That is, a(n) = (number with rank ≥ 2) − (number with rank ≥ 3).

For one term, `PartitionRankCount[2, n]` evaluates the sum above for n ≤ 1000 and uses the series division of `PartitionRankCountList` above that, as described in [Performance](A101198.md#performance).

## Checks

`test/wolfram/A101198.wlt` checks the examples on this page, the OEIS DATA section of A101199 (58 terms), and every `N(2, n)` with n ≤ 24 against a count of `IntegerPartitions`. In addition, `PartitionRankCountList[2, 10000]` was compared with all 10,000 values of the OEIS b-file (Seiichi Manyama), with no mismatches.
