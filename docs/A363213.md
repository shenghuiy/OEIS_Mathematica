# A363213: partitions of n with rank 4

[A363213](https://oeis.org/A363213) is the number of partitions of n with rank 4, where the rank of a partition is its largest part minus its number of parts. It has no package of its own: it is `PartitionRankCount[4, n]` from `src/wolfram/A101198.wl`, the package for rank 1. The derivation, the proof of the generating function and the timings are on the [A101198](A101198.md) page; this page gives what is specific to rank 4. Ranks 1, 2 and 3 are A101198, A101199 and A101200, but rank 4 was added to the OEIS much later, in 2023 (A101201 is an unrelated sequence about kings on a toroidal board).

**Notation.** As on the A101198 page, `N(m, n)` is the number of partitions of n with rank m and `p(n)` is `PartitionsP[n]`.

## The sequence

The terms for n = 1, 2, 3, … begin

```
0, 0, 0, 0, 1, 0, 1, 1, 2, 2, 4, 4, 6, 7, 11, 12, 18, 20, 28, 33, ...
```

For example a(11) = 4: the partitions 8+1+1+1, 7+3+1, 7+2+2 and 6+5 each have a largest part four more than their number of parts. The first nonzero term is a(5) = 1, from the single part 5. By conjugation, a(n) also counts the partitions of n with rank −4.

The OEIS entry gives no asymptotic. The one given for ranks 1 and 2, π e^(π√(2n/3)) / (3 · 2^(9/2) · n^(3/2)), fits numerically: the ratio of a(n) to it is 0.912, 0.985 and 0.997 at n = 100, 1000 and 10000.

## The formula for rank 4

Dyson's rank generating function, equation (2.12) of Atkin and Swinnerton-Dyer (1954), with m = 4:

```
Sum_{n>=1} N(4, n) x^n  =  Sum_{k>=1} (-1)^(k-1) x^(k(3k+7)/2) (1 - x^k)  /  Prod_{r>=1} (1 - x^r)
```

since k(3k − 1)/2 + 4k = k(3k + 7)/2. This is the generating function in the OEIS entry, written there as `x^(4k) (x^(k(3k−1)/2) − x^(k(3k+1)/2))`. Reading off the coefficient of xⁿ, the two offsets are k(3k+7)/2 and 3k(k+3)/2:

```
a(n)  =  p(n-5) - p(n-6) - p(n-13) + p(n-15) + p(n-24) - p(n-27) - ...
```

with p(j) = 0 for j < 0. As for [rank 2](A101199.md#the-formula-for-rank-2), the two halves of the sum count the partitions with rank at least 4 and at least 5, so a(n) is their difference. The first offsets k(3k+7)/2 = 5, 13, 24, … are the second offsets of the [rank-3](A101200.md#the-formula-for-rank-3) formula.

For one term, `PartitionRankCount[4, n]` evaluates the sum above for n ≤ 1000 and uses the series division of `PartitionRankCountList` above that, as described in [Performance](A101198.md#performance).

## Checks

`test/wolfram/A101198.wlt` checks the examples on this page, the OEIS DATA section of A363213 (57 terms), and every `N(4, n)` with n ≤ 24 against a count of `IntegerPartitions`. In addition, `PartitionRankCountList[4, 10000]` was compared with all 10,000 values of the OEIS b-file (Seiichi Manyama), with no mismatches.
