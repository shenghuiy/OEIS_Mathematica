# A316667: the trapped knight

`src/wolfram/A316667.wl` is a Wolfram Language package (context `OEIS`) for [A316667](https://oeis.org/A316667). Number the squares of an infinite chessboard along a square spiral, 1 at the centre. A knight starts on square 1 and always moves to the unvisited square with the smallest number. After 2016 moves it has no unvisited square left to go to, and the sequence lists the squares it visited.

## The sequence

The terms begin

```
1, 10, 3, 6, 9, 4, 7, 2, 5, 8, 11, 14, ...
```

The walk has 2016 terms and ends on square 2084.

![The trapped knight's path, with wavy colour](img/trappedKnight.svg)

## Loading and calling

From the repository root:

```wolfram
Get["src/wolfram/A316667.wl"];
OEIS`A316667[]      (* the 2016 terms *)
```

`A316667[]` takes no argument and returns the whole walk as a list of integers.

## How it works

- `SquareSpiralPoints[120]` gives the first 120² spiral coordinates, which cover every square the knight can reach. `gridIdx` maps each coordinate to its spiral number.
- A hash table holds the unvisited squares. `knightNext` removes the current square, keeps the knight moves that are still in the table, and picks the one with the smallest number.
- `Nest` runs 2016 steps, pushing each square onto a stack. When no move is left, `knightNext` returns 0, which ends the walk.
- The stack's elements are mapped back to spiral numbers.

`SquareSpiralPoints` and `PositionLargestBy` are Wolfram Function Repository functions, so the first call needs network access.

## Checks run

Run `test/wolfram/A316667.wlt`. It checks the first 12 terms, the length 2016 with last term 2084, and that no square repeats.
