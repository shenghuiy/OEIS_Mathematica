# A101198: partitions of n with rank 1

`src/wolfram/A101198.wl` is a Wolfram Language package (context `OEIS`) for [A101198](https://oeis.org/A101198), the number of partitions of n with rank 1. Dyson defined the rank of a partition as its largest part minus its number of parts. The package counts partitions of any rank m, so it also gives [A047993](https://oeis.org/A047993) (rank 0), [A101199](https://oeis.org/A101199) (rank 2), [A101200](https://oeis.org/A101200) (rank 3), and in general the columns of the triangle [A063995](https://oeis.org/A063995) of partitions of n by rank.

**Notation.** `N(m, n)` is the number of partitions of n with rank m, and `p(n)` the number of all partitions of n, `PartitionsP[n]` in Wolfram. `(x)_k = (1 − x)(1 − x²)⋯(1 − xᵏ)`.

## The sequence

The terms for n = 1, 2, 3, … begin

```
0, 1, 0, 1, 1, 2, 1, 3, 3, 5, 5, 8, 8, 13, 14, 20, 23, 31, 35, 48, ...
```

For example a(8) = 3: the partitions 5+1+1+1, 4+3+1 and 4+2+2 each have a largest part one more than their number of parts. The OEIS entry gives the asymptotic a(n) ~ π e^(π√(2n/3)) / (3 · 2^(9/2) · n^(3/2)) (Kotesovec); the ratio of a(n) to it is 0.971, 0.991 and 0.997 at n = 100, 1000 and 10000.

## Loading and calling

From the repository root:

```wolfram
Get["src/wolfram/A101198.wl"];
OEIS`A101198[8]                       (* 3 *)
OEIS`PartitionRankCountList[1, 20]    (* the 20 terms above *)
OEIS`PartitionRankCount[3, 20]        (* 40, the 20th term of A101200 *)
OEIS`PartitionRankCount[-3, 20]       (* 40 as well: conjugation reverses the rank *)
OEIS`A101198 /@ {100, 1000}           (* {6203548, 245302742607816804169710132801} *)
```

## Public functions

| Call | Returns |
|---|---|
| `A101198[n]` | The number of partitions of n with rank 1. |
| `PartitionRankCount[m, n]` | `N(m, n)`, the number of partitions of n with rank m, for any integer m. |
| `PartitionRankCountList[m, nmax]` | `{N(m, 1), …, N(m, nmax)}`, all computed together. |

`n` and `nmax` are positive integers and `m` is an integer. Otherwise the function gives a message (`::posint` or `::int`) and returns `$Failed`. Like the OEIS entries, the sequences start at n = 1, so the empty partition is not counted.

## How it works

1. **Dyson's generating function.** For m ≥ 0,

   ```
   Sum_{n>=1} N(m, n) x^n  =  Sum_{k>=1} (-1)^(k-1) x^(k(3k-1)/2 + m k) (1 - x^k)  /  Prod_{r>=1} (1 - x^r)
   ```

   This is equation (2.12) of Atkin and Swinnerton-Dyer (1954), who credit it to Dyson (1944) and prove it as their Lemma 1. Ranks below 0 follow from `N(−m, n) = N(m, n)`: conjugating a partition (transposing its Ferrers diagram) swaps the largest part and the number of parts.
2. **Why it holds (Lemma 1).** A partition of n with s parts and rank m ≥ 0 has largest part s + m. Removing it leaves a partition of n − s − m into exactly s − 1 parts, each at most s + m. Two identities of Cauchy (Hardy and Wright, Theorems 348 and 349, with `[N, u]` the Gaussian binomial `Prod_{t=1}^{u} (1 − x^(N−t+1))/(1 − x^t)`)

   ```
   Prod_{v=1}^{j} (1 + a x^v)     =  Sum_{u=0}^{j}  a^u x^(u(u+1)/2) [j, u]
   Prod_{v=1}^{j} (1 - a x^v)^-1  =  Sum_{u>=0}     a^u x^u [j+u-1, u]
   ```

   turn the count for each s into an alternating sum over u. After summing over s and swapping the two sums, the inner sum over s is `x^(u²) Σ_k x^(k(u+1)) / (x)_k`. By Euler's identity `Σ_k aᵏ xᵏ / (x)_k = Π_{v≥1} 1/(1 − a xᵛ)` (the second identity as j → ∞) with a = xᵘ, this is `x^(u²) / Π_{r>u} (1 − xʳ)`, which cancels the product `Π_{r>u} (1 − xʳ)` in front of it. What is left of the u-th term is `(−1)^(u−1) x^(u(u−1)/2 + mu + u²) (1 − xᵘ)`, and `u(u − 1)/2 + u² = u(3u − 1)/2` gives (2.12). Each Cauchy identity follows by comparing coefficients of aᵘ in a functional equation, `(1 + ax) F(ax) = (1 + a x^(j+1)) F(a)` for the first product F and `(1 − ax) G(a) = (1 − a x^(j+1)) G(ax)` for the second G, which gives a one-step recurrence for the coefficients.
3. **One term.** Expanding `1/Π(1 − xʳ) = Σ p(j) xʲ` and reading off the coefficient of xⁿ:

   ```
   N(m, n)  =  Sum_{k>=1} (-1)^(k-1) [ p(n - k(3k-1)/2 - m k) - p(n - k(3k+1)/2 - m k) ]
   ```

   with p(j) = 0 for j < 0. The sum stops once `k(3k − 1)/2 + mk > n`, so it has at most about √(2n/3) terms. For rank 1 the offsets are k(3k+1)/2 and 3k(k+1)/2:

   ```
   a(n)  =  p(n-2) - p(n-3) - p(n-7) + p(n-9) + p(n-15) - p(n-18) - ...
   ```

   `A101198` and `PartitionRankCount` evaluate this sum with `PartitionsP` for n ≤ 1000. For larger n they take the last entry of the list in step 4, which is faster (see Performance).
4. **Many terms.** `PartitionRankCountList` divides the numerator of (2.12) by Euler's pentagonal series `Π(1 − xʳ) = 1 + Σ_{k≥1} (−1)ᵏ (x^(k(3k−1)/2) + x^(k(3k+1)/2))` once, with `Series`, and reads off every coefficient up to x^nmax.

**Garden of Eden partitions.** Summing (2.12) over m ≥ 2 telescopes, since `Σ_{m≥2} x^(mk) = x^(2k)/(1 − xᵏ)`, to `Σ_{m≥2} N(m, n) = Σ_{k≥1} (−1)^(k+1) p(n − 3k(k+1)/2)`. By conjugation this counts the partitions with rank at most −2, which are the Garden of Eden partitions of Bulgarian solitaire, and it is the Hopkins–Sellers formula behind `BulgarianSolitaireGardenOfEdenCount` (see [Bulgarian solitaire](BulgarianSolitaire.md)).

## Performance

First call in a fresh kernel (`wolframscript`, Mathematica 15.0.1 on Windows):

| n | `PartitionsP` sum (one term) | series division (all terms up to n) |
|---|---|---|
| 1,000 | 0.002 s | 0.03 s |
| 1,500 | 0.35 s | 0.04 s |
| 2,000 | 0.54 s | 0.05 s |
| 5,000 | 1.5 s | 0.16 s |
| 10,000 | 2.8 s | 0.52 s |
| 100,000 | 26 s | 12.8 s |

Up to n = 1000 the sum costs about 2 ms. Above that, each new `PartitionsP` value takes milliseconds (about 0.02 s near n = 10⁴), and the sum needs about 2√(2n/3) of them, so from n ≈ 1500 on the series division is the faster way to get even one term. `A101198[n]` and `PartitionRankCount[m, n]` therefore use the sum for n ≤ 1000 and the series division above (the cutoff is `rankSumCutoff` in the package), so their time is the faster column of the table. Above n = 1000 each call builds the list again, so for a table use `PartitionRankCountList`.

## Checks

Run `test/wolfram/A101198.wlt`. It checks:

- the examples on this page;
- the DATA sections of the OEIS entries for ranks 0 to 3 (A047993, A101198, A101199, A101200);
- values from the A101198 b-file at n = 100, 500 and 1000, with both the list and the single-term function;
- every `N(m, n)` with |m| ≤ 6 and n ≤ 24 against a count of `IntegerPartitions`, and the list form against single terms for m = −3 to 4 and n ≤ 300;
- that the counts over all ranks add up to p(n), the extreme ranks ±(n − 1), and the Hopkins–Sellers sum for ranks ≥ 2;
- the messages for invalid arguments.

In addition, `PartitionRankCountList[1, 10000]` was compared with all 10,000 values of the OEIS b-file (Seiichi Manyama), with no mismatches.
