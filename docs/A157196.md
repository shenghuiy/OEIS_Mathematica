# A157196: self-describing sequence of 1s and 2s

`src/A157196.wl` is a Wolfram Language package (context `OEIS`) for [A157196](https://oeis.org/A157196) (Benoit Cloitre, February 2009; offset 1). Its terms are all 1 or 2, and the sequence describes itself: a(n) is half the sum of the elements of the n-th run, where the sequence is cut into runs that each use only 1 and 2 starting from 1, 1. The Wolfram Language code is a string construction contributed by Shenghui Yang.

## The sequence

The terms begin

```
1, 1, 2, 1, 1, 1, 1, 2, 1, 1, 2, 1, 1, 2, 2, 1, 1, 2, 1, 1, 1, 1, 2, ...
```

The OEIS entry comments that the density of 1s is conjectured to be 2/3 (proved by Shallit). In the first 2¹⁴ terms computed here, the proportion of 1s is 0.66669.

## Loading and calling

From the repository root:

```wolfram
Get["src/A157196.wl"];
Array[OEIS`A157196, 10]      (* {1, 1, 2, 1, 1, 1, 1, 2, 1, 1} *)
```

`A157196[n]` takes a positive integer `n` and returns the n-th term as an integer.

## How it works

The code builds a string of digits `a[k]`, starting from `a[0] = "11"`. Each step appends a block derived from the reverse of the current string `s`:

- If `s` starts with `"11"`, append `"2"` followed by `s` with its first two characters removed.
- Otherwise append `"11"` followed by `s` with its first character removed.

Each string is a prefix of the next, so the strings converge to the sequence. The first few are `"11"`, `"112"`, `"1121111"`, `"1121111211211"`. The lengths are 2, 3, 7, 13, 25, 49, 97, 193, … that is, 3·2ᵏ⁻¹ + 1 for k ≥ 1.

`A157196[n]` finds the smallest `k` with `StringLength[a[k]] >= n` and reads character `n` of `a[k]`. The strings are memoized, so repeated calls reuse earlier work. The helper functions `strA157196` and `levelA157196` live in `` OEIS`Private` ``; only `A157196` is public.

## Checks run

Run with `wolframscript`:

- `Array[A157196, 105]` equals the 105 terms listed in the OEIS data section.
- Joining `Array[A157196, 193]` gives exactly `a[7]`, the string in the original code comment.
