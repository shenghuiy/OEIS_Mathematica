# A003785: eta-quotient sequence translated from PARI/GP

`src/A003785.wl` is a Wolfram Language package (context `OEIS`) for [A003785](https://oeis.org/A003785). It is a translation of the PARI/GP program from the OEIS entry, which builds the terms from a product of Dedekind eta functions. See the OEIS page for the sequence's definition, offset and data; the terms are not reproduced here.

## Loading and calling

From the repository root:

```wolfram
Get["src/A003785.wl"];
Array[OEIS`A003785, 20]
```

`A003785[n]` takes an integer `n` and returns the n-th term. As in the PARI program, it returns 0 for `n < 3`. The helper `etaSeries[k, nn]` is also public.

## The PARI program

```gp
{a(n) = local(A, A1); if( n<3, 0, n -= 3; A = x * O(x^n);
  A1 = (eta(x^2 + A)^3 / eta(x + A) / eta(x^4 + A)^2)^4;
  polcoeff( (A1 + 4 * x / A1) * eta(x^2 + A)^7 * eta(x^4 + A)^18 / eta(x + A)^2, n))}
```

## How the translation works

For a power series argument, PARI's `eta(x^k + A)` is the product ∏ₘ≥₁ (1 − x^(km)), without the usual x^(1/24) factor. In Mathematica that is `QPochhammer[x^k, x^k]`. Since only coefficients up to x^m (with m = n − 3) matter, `etaSeries[k, nn]` truncates the product after x^nn:

```wolfram
etaSeries[k_, nn_] := Normal@Series[QPochhammer[x^k, x^k, nn + 1], {x, 0, nn}]
```

The rest maps one-to-one:

| PARI | Wolfram Language |
|---|---|
| `eta(x + A)`, `eta(x^2 + A)`, `eta(x^4 + A)` | `e1`, `e2`, `e4` = `etaSeries[1, m]`, `etaSeries[2, m]`, `etaSeries[4, m]` |
| `A1 = (eta(x^2)^3 / eta(x) / eta(x^4)^2)^4` | `A1 = Series[(e2^3/e1/e4^2)^4, {x, 0, m}]` |
| `polcoeff(..., n)` | `SeriesCoefficient[..., {x, 0, m}]` |

`A1` has constant term 1, so `4 x/A1` is a valid power series. The symbol `x` lives in `` OEIS`Private` ``; only `A003785` and `etaSeries` are public.
